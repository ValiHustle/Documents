# Hand Tracking Interactive

Браузерный интерактив с трекингом руки: вместо захвата объектов вы теперь отталкиваете рой частиц пинч-жестом, и они хаотично летают по экрану.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`, затем нажмите **«Включить камеру»** и разрешите доступ в браузере.

> Если открыть страницу не на `localhost` и не по HTTPS, камера не запустится (ограничение браузеров).

## Управление

1. Нажмите кнопку запуска камеры.
2. Покажите ладонь в кадре.
3. Сведите большой и указательный пальцы (pinch), чтобы включить импульс отталкивания.
4. Подносите pinch-курсор к частицам — они будут разлетаться и отражаться от границ сцены.
5. Используйте окно настроек, чтобы менять количество, размер, цвет и скорость частиц.

## Технологии

- HTML/CSS/Vanilla JavaScript
- MediaPipe Hands (через CDN)
- Web API: `navigator.mediaDevices.getUserMedia`
