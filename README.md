# Hand Tracking Interactive

Небольшой браузерный интерактив: камера отслеживает руку, а жест "pinch" (сведение большого и указательного пальцев) позволяет захватывать и перемещать объекты на экране.

## Что изменено

- Оверлей руки теперь зеркалится тем же CSS-трансформом, что и видео, поэтому скелет совпадает с ладонью в кадре без двойного отражения.
- Добавлены разные фигуры (круг, квадрат, треугольник, ромб, звезда).
- Добавлены эффекты: неоновое свечение, мягкое вращение фигур, пульсация при захвате и шлейф от pinch-курсора.

## Запуск как обычный сайт (без терминала)

Рекомендуемый вариант — **GitHub Pages** (HTTPS, камера работает):

1. Загрузите проект в GitHub-репозиторий.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
4. Запушьте изменения в ветку `main`, `master` или `work`.
5. После выполнения workflow откройте сайт по ссылке вида:
   `https://<username>.github.io/<repo>/`

В проект уже добавлен workflow для авто-публикации: `.github/workflows/deploy-pages.yml`.

## Локальный запуск (если нужен)

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`, затем нажмите **«Включить камеру»** и разрешите доступ в браузере.

> Если открыть страницу не на `localhost` и не по HTTPS, камера не запустится (ограничение браузеров).

## Управление

1. Нажмите кнопку запуска камеры.
2. Покажите ладонь в кадре.
3. Подведите указательный и большой пальцы к ближайшей фигуре.
4. Сведите пальцы — фигура захватится.
5. Двигайте рукой, чтобы перетаскивать фигуру.
6. Разведите пальцы, чтобы отпустить.

## Технологии

- HTML/CSS/Vanilla JavaScript
- MediaPipe Hands (через CDN)
- Web API: `navigator.mediaDevices.getUserMedia`
