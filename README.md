# Hand Tracking Interactive

Небольшой браузерный интерактив: камера отслеживает руку, а жест "pinch" (сведение большого и указательного пальцев) позволяет захватывать и перемещать объекты на экране.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173` и разрешите доступ к камере.

## Управление

1. Покажите ладонь в кадре.
2. Подведите указательный и большой пальцы к ближайшему шару.
3. Сведите пальцы — шар захватится.
4. Двигайте рукой, чтобы перетаскивать шар.
5. Разведите пальцы, чтобы отпустить.

## Технологии

- HTML/CSS/Vanilla JavaScript
- MediaPipe Hands (через CDN)
