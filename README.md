# Hand Tracking Interactive

Небольшой браузерный интерактив: камера отслеживает руку, а жест "pinch" (сведение большого и указательного пальцев) позволяет захватывать и перемещать объекты на экране.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`, затем нажмите **«Включить камеру»** и разрешите доступ в браузере.

> Если открыть страницу не на `localhost` и не по HTTPS, камера не запустится (ограничение браузеров).

## Управление

1. Нажмите кнопку запуска камеры.
2. Покажите ладонь в кадре.
3. Подведите указательный и большой пальцы к ближайшему шару.
4. Сведите пальцы — шар захватится.
5. Двигайте рукой, чтобы перетаскивать шар.
6. Разведите пальцы, чтобы отпустить.

## Технологии

- HTML/CSS/Vanilla JavaScript
- MediaPipe Hands (через CDN)
- Web API: `navigator.mediaDevices.getUserMedia`
